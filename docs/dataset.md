# Dataset
## 1. e-stat
### 1.1 数据来源 www.e-stat.go.jp
### 1.2 数据内容
- 経済センサス-活動調査: 市区町村別、産業分類別に売上高や付加価値額、従業者数がわかるデータ。
- 国勢調査: 市区町村別、年齢階級別の人口データ。特に**生産年齢人口（15～64歳）や若年層（15～29歳）**のデータが重要。
- 小売物価統計調査: 主要な都市別（県庁所在地など）の品目別の小売価格データ。
- 家計調査: 都市別の二人以上世帯の品目別支出金額データ。例えば「外食にかける月平均額」などがわかります。
リンク：https://www.e-stat.go.jp/stat-search/files?page=1&layout=dataset&toukei=00200502&tstat=000001225961&cycle=0&year=20250&month=0&tclass1=000001225962

### 1.3 提问示例
- 千葉市で一番売上が高い産業は何？
- では、その千葉市の働き手の中心である生産年齢人口は、今後どうなっていく？
- 千葉市で今後10年で最も働き手が不足する可能性がある、今一番儲かっている産業はどこ？
- 千葉市で一番若年層の人口が多い産業は何？

- 那覇市と東京23区では、どちらの方が『外食の費用』が高い？
- では、それぞれの都市で『ラーメン（外食）』1杯の値段はいくら？
- では、それぞれの市民が稼いだお金のうち、ラーメンを食べるためには何％を使っている？（エンゲル係数ならぬ“ラーメン係数”）
